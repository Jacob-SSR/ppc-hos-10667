## Design Context

### Users
Hospital medical records and statistics staff search patient statistics by ICD-10, age and visit dates.

### Brand Personality
Clear, trustworthy, practical. Keep the existing application tone.

### Aesthetic Direction
The user explicitly selected the existing application appearance, rather than the dark reference HTML. Reuse its light report surfaces, green controls, Thai text and responsive tables.

### Design Principles
- Match existing reports.
- Distinguish visit counts from unique patient counts.
- Explain which visit supplies each patient's diagnosis text.
- Keep filters, loading, errors and exports clear.
