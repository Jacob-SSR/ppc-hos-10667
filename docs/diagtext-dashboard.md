# Dashboard ข้อความวินิจฉัย (diagtext)

หน้า `/pages/diagtext-dashboard` และ API `/api/diagtext-dashboard` อยู่ในสิทธิ์ REPORT (เมนู “diagtext ที่ลงมากที่สุด” ในหมวดรายงาน)

## ดูอะไรได้

- เลือกปีงบประมาณ (ปีปัจจุบัน + ย้อนหลัง 5 ปี) แล้วเลือกช่วงที่ดู: ทั้งปีงบ / รายไตรมาส / รายเดือน / รายวัน
- ทุกช่วงแสดง: ครั้งรับบริการ OPD, ครั้งที่ลง diagtext แล้ว (และที่ยังไม่ลง), ข้อความไม่ซ้ำ, diagtext ที่ลงมากที่สุด (10 อันดับ กดดูได้ถึง 50) และอันดับผู้ลง diagtext
- ตาราง “อันดับ 1–3 ของแต่ละเดือนและไตรมาส” สรุปทั้งปีงบในตารางเดียว กดแถวเพื่อเปิดช่วงนั้น
- กราฟรายเดือน (ทั้งปีงบ/ไตรมาส) กดแท่งเพื่อเปิดเดือนนั้น; กราฟรายวัน (รายเดือน) กดแท่งเพื่อเปิด visit ของวันนั้น
- รายวัน: เลือกวัน (ปุ่มก่อน/ถัดไป/วันนี้) เห็น diagtext ที่เยอะสุดของวัน ผู้ลง และรายการ visit (เวลา, VN/HN, แผนก, ข้อความ, ผู้ลง)
- ส่งออก CSV ของช่วงที่ดูอยู่ (อันดับข้อความ + อันดับผู้ลง)

## แหล่งข้อมูลและการนับ

- ข้อความ: `ovst_doctor_diag.diag_text` (ที่แพทย์พิมพ์ในหน้าจอแพทย์ — แหล่งเดียวกับ incomplete-visit) เชื่อม `ovst` ด้วย `vn` ใช้ `ovst.vstdate` เป็นวันที่
- ครั้งรับบริการ OPD = จำนวนแถวใน `ovst` ของช่วงนั้น; “ลงแล้ว” = VN ที่มี diag_text ไม่ว่าง
- ช่องเดียวหลายบรรทัดนับแยกบรรทัด ตัดเลขข้อ/ขีดนำหน้า (`1.`, `2)`, `-`) ช่องว่างซ้ำ และจุดท้าย แล้วเทียบแบบไม่สนตัวพิมพ์ (`HT`, `ht`, `1. HT` = ข้อความเดียวกัน) บรรทัดที่ไม่มีตัวอักษร (`-`, `.`, `NULL`) ไม่นับ
- อันดับข้อความนับครั้งรับบริการ (VN) ที่มีข้อความนั้น
- ผู้ลง: อ่าน `information_schema` หาคอลัมน์ใน `ovst_doctor_diag` ตามลำดับ `doctor_code`, `doctor` (ชื่อจาก `doctor`), `staff`, `entry_staff` (ชื่อจาก `opduser`) — ไม่มีสักคอลัมน์จะใช้แพทย์ของโรคหลัก `ovstdiag.doctor` (`diagtype = '1'`) แทน หน้าเว็บแสดงว่าใช้แหล่งไหนในการ์ด “ผู้ลง diagtext”
- อันดับผู้ลงเรียงตามจำนวนรายการ (แถว ovst_doctor_diag) ที่ลง แล้วตามจำนวน VN; ไม่มีรหัสผู้ลงรวมเป็น “ไม่ระบุผู้ลง”
- ไตรมาสปีงบ: Q1 ต.ค.–ธ.ค., Q2 ม.ค.–มี.ค., Q3 เม.ย.–มิ.ย., Q4 ก.ค.–ก.ย.

## ประสิทธิภาพ

- รายปีงบ: รวมยอดใน MySQL (เดือน × ข้อความ, เดือน × ผู้ลง, รายวัน) 4 query ต่อปีงบ แล้ว cache ผ่าน `cachedJson` — ปีงบปัจจุบัน 30 นาที ปีงบที่ปิดแล้ว 6 ชั่วโมง
- รายวัน: cache 2 นาที จำกัด 20,000 แถวต่อวัน (เกินจะแจ้งบนหน้า)
- คอลัมน์ผู้ลง cache 1 วัน
