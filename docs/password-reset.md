# ตั้งรหัสผ่านใหม่โดย IT

1. ล็อกอินด้วยบัญชีที่มี role `IT` (ตรวจสิทธิ์ปัจจุบันจากฐานข้อมูล)
2. เปิดเมนู **จัดการผู้ใช้ / รหัสผ่าน** (`/pages/user-permissions`)
3. ค้นหาชื่อหรือ username แล้วเลือกบัญชี
4. กรอกรหัสผ่านใหม่สองครั้ง เลือกยืนยันชื่อบัญชี แล้วกด **ยืนยันตั้งรหัสผ่านใหม่**
5. แจ้งรหัสใหม่ให้เจ้าของบัญชีผ่านช่องทางส่วนตัว ผู้ใช้เปลี่ยนรหัสของตัวเองต่อได้ที่ตั้งค่าบัญชี

ไม่ต้องใช้รหัสผ่านเดิม ไม่ต้องรัน Node หรือสร้าง JWT เอง รหัสใหม่บันทึกเป็น bcrypt cost 12 ใน `ppchos.users.passweb` จึงใช้กับหน้า login เดิมได้ ทั้งบัญชีที่เดิมเก็บ MD5 และ bcrypt โดยไม่แก้ role หรือสิทธิ์รายงาน

รหัสใหม่ต้องมีอย่างน้อย 6 ตัวอักษร ไม่เกิน 72 ไบต์ UTF-8 และไม่มีช่องว่างต้น/ท้าย เพราะหน้า login เดิมตัดช่องว่างออก

API: `POST /api/user-permissions/reset-password` รับ JSON `{ "username": "...", "newPassword": "..." }` ใช้ session cookie และ same-origin request อนุญาตเฉพาะ IT จำกัด 20 คำขอต่อ 5 นาทีต่อ IT และตรวจสิทธิ์อีกครั้งขณะล็อกแถวใน transaction

ประวัติอยู่ใน `ppchos.password_reset_audit` เก็บผู้เปลี่ยน บัญชีปลายทาง และเวลา ไม่เก็บรหัสผ่านหรือ hash การอัปเดตรหัสผ่านและประวัติต้องสำเร็จพร้อมกัน หากสร้างตารางไม่ได้ ให้ DBA รัน `docs/sql/user_access.sql` และ `docs/sql/password_reset_audit.sql` บน DB_HOST2 ก่อน บัญชีฐานข้อมูลของแอปต้องมีสิทธิ์ SELECT/UPDATE ตาราง users และ SELECT/INSERT ตารางประวัติ

ขอบเขต: เปลี่ยนเฉพาะรหัสผ่านเว็บ `passweb` ไม่เปลี่ยนรหัส HOSxP ส่วนอื่น การตั้งรหัสใหม่ไม่ได้ยกเลิก JWT ที่ออกไปแล้ว (อายุเดิม 8 ชั่วโมง) ไม่บังคับเปลี่ยนรหัสเมื่อเข้าใช้ครั้งแรก และไม่ล้างตัวจำกัดความถี่การ login เดิม ถ้าบัญชีติดจำกัดความถี่ ให้รอครบช่วงเวลาที่หน้า login แจ้ง

ทดสอบ: `node --test tests/password-reset.test.mjs tests/user-permissions.test.mjs` และ `npx tsc --noEmit`
